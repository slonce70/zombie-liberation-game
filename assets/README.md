# Game assets

- `concept/zombie-liberation-concept.png` is the ImageGen visual direction reference for the game: colorful kid-friendly heroes, silly zombies, level path, and a top-corner country map.
- Runtime character visuals are CSS/emoji sprite tokens inspired by the hatch-pet workflow: compact silhouettes, readable states, no gore, no copied characters, and simple idle animation.

## Sprite policy

Generated fighter/zombie sprites should follow `docs/art/sprite-generation-prompts.md` and remain kid-safe: no blood, no gore, no scary horror, no copied characters, no readable logos. If generated sprites are not available, the game uses emoji/CSS sprite tokens as a safe fallback.
