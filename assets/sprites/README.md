# Sprite Assets

This folder is prepared for Hatch Pet-like generated sprites.

Current game code supports both:

1. per-state MVP assets, for example `assets/sprites/fighters/artem-idle.webp`, and
2. future atlas assets, for example `assets/sprites/fighters/artem/spritesheet.webp`.

Generation source of truth:

- `docs/art/imagegen-concept-analysis.md`
- `docs/art/hatch-pet-adapted-sprite-pipeline.md`
- `docs/art/entity-imagegen-prompts.md`
- `docs/art/sprite-generation-prompts.md`
